# Student Course Management App

A Spring Boot application to manage Students and Courses.

## Tech Stack
- Spring Boot 3.2.5, Java 21
- Spring Data JPA + H2
- Thymeleaf
- JUnit 5 + Mockito

## Run
Open in IntelliJ and run `StudentCourseAppApplication.java`
App runs on http://localhost:8081

## Features
- Add, view, edit Students and Courses
- Duplicate email/title validation
- 11 unit tests passing
